# LUXCAR

Web stranica auto salona LUXCAR iz Gradiške. Statički HTML, CSS i JavaScript.

Vozila i galerije uređuju se u `js/cars.js`; fotografije su u folderu `slike`.

## Lokalni pregled

Pokrenite `python -m http.server 8000` u folderu projekta i otvorite `http://localhost:8000`.

## Objavljivanje

Stranica se objavljuje putem GitHub Pages sa grane `main`, iz korijena repozitorija.
